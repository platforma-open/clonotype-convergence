# Clonotype Convergence

Platforma.bio block that detects antigen-driven clonotype convergence in BCR repertoires by wrapping the fast-STAR statistic (Abbate et al. 2024) from [statbiophys/STAR](https://github.com/statbiophys/STAR).

Heavy chain is the primary signal; light chain is optional and exploratory.

Current development branch: [`MILAB-6354_clonotype-convergence`](../../tree/MILAB-6354_clonotype-convergence).
